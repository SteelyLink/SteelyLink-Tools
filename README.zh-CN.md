## 为什么会有这个网站

几乎所有「免费在线转换器」的做法都一样：你把文件交出去，它被传到一台你一无所知的服务器上，然后你只能祈祷一切安好。你的旅行照片、签好字的合同、身份证扫描件——统统躺在别人的硬盘上，受制于别人的留存策略。

SteelyLink Tools 建立在完全相反的前提上。**你的文件永远不会离开你的设备。**

图像编解码器、PDF 引擎、OCR 文字识别、音频处理，甚至 AI 抠图，全部被编译成 WebAssembly，由你自己的浏览器标签页执行。没有可以被攻破的上传接口，没有可以泄漏的存储桶，也没有需要注销的账号——因为这些东西根本就不存在。整个网站只是一组预渲染好的静态文件，我的服务器发给你的唯一东西就是 HTML。

|  | |
| :--- | :--- |
| **不上传任何东西** | 每一个字节的处理都在本地完成。页面加载完成后把网络断开，工具照常工作。 |
| **不存储任何东西** | 没有数据库、没有用户账号、没有文件留存。你的数据无处可存。 |
| **不追踪任何东西** | 没有广告脚本、没有行为分析、没有跨站追踪像素。 |
| **不设任何付费墙** | 全部 111 个工具、全部功能，没有次数限制，没有水印，没有「专业版」。 |
| **不需要安装** | 电脑、平板、手机上的任意现代浏览器，打开就能用。 |

## 技术实现

| | |
| :--- | :--- |
| **框架** | Next.js 15（App Router）+ React 19 + TypeScript |
| **渲染** | 完全静态导出——每个页面都是预渲染好的 HTML，没有服务端运行时 |
| **样式** | Tailwind CSS，深色优先设计，自托管的图标字体子集 |
| **国际化** | next-intl，六个语言前缀，每种语言独立的元数据、站点地图和订阅源 |
| **托管** | Cloudflare Pages |
| **规模** | 1,411 个预渲染页面 · 111 个工具 · 每种语言 111 篇深度文章 |

所有的重活都在客户端由 WebAssembly 完成：

- **图像** — `@jsquash`（AVIF、JPEG、PNG、WebP、oxipng）、`heic2any` 处理 iPhone 的 HEIC、`gifenc` 编码动态 GIF
- **PDF** — `pdf-lib` 负责生成与编辑，`pdf.js` 负责解析与渲染
- **文档** — `mammoth` 和 `docx` 实现 Word 的双向转换
- **OCR** — `tesseract.js` 识别图片和扫描版 PDF 中的文字
- **AI** — `@huggingface/transformers` 在本地运行分割模型实现抠图
- **音频** — `@jitsi/rnnoise-wasm` 降噪，`lamejs` 编码 MP3

没有 API 密钥，没有第三方处理服务，没有按次计费。这正是它能够把全部功能永久免费提供出来的原因。

<br>

## 本地运行

```bash
git clone https://github.com/SteelyLink/SteelyLink-Tools.git
cd SteelyLink-Tools
npm install
npm run dev          # http://localhost:3000
```

生成与线上完全一致的静态站点：

```bash
npm run build                # 完整静态站点输出到 ./out
npx wrangler pages dev out   # 预览构建结果
```

`npm run build` 同时会重新生成站点地图、RSS 订阅源和 Web 应用清单，并校验注册表里的每一个工具都能解析到真实存在的页面。
