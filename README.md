## Why this exists

Almost every "free online converter" works the same way: you hand over your file, it travels to a server you know nothing about, and you hope for the best. Your holiday photos, your signed contracts, your ID scans — uploaded to someone else's disk, subject to someone else's retention policy.

SteelyLink Tools is built on the opposite premise. **Your file never leaves your device.**

Image codecs, PDF engines, OCR, audio processing, even AI background removal are compiled to WebAssembly and executed by your own browser tab. There is no upload endpoint to breach, no storage bucket to leak, and no account to delete — because none of them exist. The entire site is a set of pre-rendered static files; the only thing my server ever sends you is HTML.

|  | |
| :--- | :--- |
| **Nothing is uploaded** | Every byte of processing happens locally. Turn off your Wi-Fi after the page loads and the tools keep working. |
| **Nothing is stored** | No database, no user accounts, no file retention. There is nowhere for your data to sit. |
| **Nothing is tracked** | No advertising scripts, no behavioural analytics, no cross-site pixels. |
| **Nothing is paywalled** | All 111 tools, all features, no quotas, no watermarks, no "pro" tier. |
| **Nothing to install** | Works in any modern browser on desktop, tablet and phone. |

## Under the hood

| | |
| :--- | :--- |
| **Framework** | Next.js 15 (App Router) with React 19 and TypeScript |
| **Rendering** | Fully static export — every page is pre-rendered HTML, no server runtime |
| **Styling** | Tailwind CSS, dark-first design, self-hosted icon font subset |
| **i18n** | next-intl with six locale prefixes and per-locale metadata, sitemap and feed |
| **Hosting** | Cloudflare Pages |
| **Scale** | 1,411 pre-rendered pages · 111 tools · 111 in-depth articles per locale |

Everything heavy runs client-side in WebAssembly:

- **Images** — `@jsquash` (AVIF, JPEG, PNG, WebP, oxipng), `heic2any` for iPhone HEIC, `gifenc` for animated GIF encoding
- **PDF** — `pdf-lib` for authoring and editing, `pdf.js` for parsing and rendering
- **Documents** — `mammoth` and `docx` for Word conversion in both directions
- **OCR** — `tesseract.js` for text recognition in images and scanned PDFs
- **AI** — `@huggingface/transformers` running a segmentation model locally for background removal
- **Audio** — `@jitsi/rnnoise-wasm` for noise suppression, `lamejs` for MP3 encoding

No API keys. No third-party processing services. No per-request costs. That is what makes it possible to offer everything for free, forever.

## Run it locally

```bash
git clone https://github.com/SteelyLink/SteelyLink-Tools.git
cd SteelyLink-Tools
npm install
npm run dev          # http://localhost:3000
```

To produce the static site exactly as it is deployed:

```bash
npm run build         # writes the full static site to ./out
npx wrangler pages dev out   # preview the built output
```

`npm run build` also regenerates the sitemap, RSS feed and web manifest, then verifies that every tool in the registry resolves to a real page.

## Contributing

Issues and pull requests are welcome — bug reports, new tool ideas, and translation fixes especially. Two ground rules keep the project what it is:

1. **No uploads.** A tool that sends user data to a server does not belong here.
2. **No third-party runtime dependencies.** No CDNs, no trackers, no external fonts. Everything ships from the origin.
